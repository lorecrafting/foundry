[Foundry](../../README.md) › [Docs](../README.md) › FR-08 files still in the tree

The FR-08 reviews, probes, candidates, raw sweeps, briefings and superseded designs are dated
records. Per operator decision Q10 they are not kept in the tree: tag `records/2026-09-24`
preserves all of them ([docs/fr-08 at the tag](https://github.com/lorecrafting/foundry/tree/records/2026-09-24/docs/fr-08)).
What stays here is what code reads or cites, plus one design note the repair plan relies on.

  `test/foundry/repair/fr08a_protected_boundary_test.exs` and regenerated by `bin/rebind_fr08a.exs`.
- `fr08a-acceptance-review-probes.exs`, `fr08a-transition-review-probes.exs` and
  `fr08a-typed-replay-correction-probes.exs`: run by `test/foundry/durable_store/fr08a_rereview_matrix_test.exs`.
  They load `fr08a-final-review-probes.exs` and `fr08a-typed-replay-review-probes.exs`.
